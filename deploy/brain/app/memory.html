恢复历史对话
把别处的备份变成这里的历史对话：导入后它们会出现在左侧对话列表里， 点进去可以接着聊，模型也能看到之前的上下文。
把备份文件拖到这里，或点击选择
支持：DeepSeek 官方导出包（.zip）· Google Takeout 的 Gemini 记录（.zip / .html）· ChatGPT 的 conversations.json · 豆包单会话 JSON · 纯文本 .txt / .md
各平台能导出什么
不同平台的导出内容差别很大，先看一下再导，避免以为数据丢了。
DeepSeek　提问 + 回答齐全，带原始时间
豆包　提问 + 回答齐全（一个文件一个会话，标题取自文件名）
ChatGPT　提问 + 回答齐全（conversations.json）
Gemini　提问 + 回答齐全，图片附件也会一起搬过来。 整包上传 Takeout 的 zip 即可，会自动找到活动记录。
说明：只搬图片附件。txt / xlsx / 压缩包这类文件在聊天里打不开， 硬塞进去只会变成一堆点不动的附件，所以跳过（原对话里仍会保留文件名）。
粘贴文本
豆包 / Kimi / 通义大多只能复制对话文本。粘贴进来，会按 用户: / 助手: 切分。
已导入的对话
带「导入」标签的对话。不想要了可以一键撤销 —— 只删导入的，你自己聊的不受影响。
